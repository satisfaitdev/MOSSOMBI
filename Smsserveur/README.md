# 📱 SERVEUR SMS MOSSOMBI - SOLUTION AUTO-HÉBERGÉE

## 🎯 OBJECTIF
Serveur SMS 100% gratuit avec PlaySMS + Gammu pour Coolify/Nixpacks

## 💰 COÛT TOTAL
- ✅ Serveur : Déjà disponible (Coolify)
- ✅ Code : 100% gratuit (open source)
- 📱 SIM locale + forfait SMS : ~$5-10/mois
- 🔌 Modem GSM : ~$30-50 (une fois)

## 🏗️ ARCHITECTURE
```
📱 Frontend Mossombi
    ↓ HTTP API
🌐 Backend Mossombi 
    ↓ HTTP API
📡 Serveur SMS (ce projet)
    ↓ USB
🔌 Modem GSM + SIM
```

## 🚀 DÉPLOIEMENT
1. Connecter modem GSM au serveur
2. Insérer SIM avec forfait SMS
3. Déployer sur Coolify avec Nixpacks
4. Configurer l'API dans Backend Mossombi

## 📋 PRÉREQUIS
- Serveur Linux avec port USB
- Modem GSM compatible (Huawei E3372, etc.)
- Carte SIM avec forfait SMS
- Coolify configuré
